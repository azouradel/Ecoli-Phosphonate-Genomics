# E. coli Phosphonate Genomics

This repository contains scripts and documentation associated with the population genomic analysis of the C-P lyase phosphonate utilization pathway across approximately 9,700 Escherichia coli genomes.

## Overview

This study investigates the distribution and conservation of phosphonate-utilization genes in a large population genomic dataset of Escherichia coli.

The repository contains scripts supporting:

- target gene detection
- genomic data processing
- statistical analysis
- figure generation

## Repository structure

- `scripts/` – scripts used for genomic and statistical analyses
- `metadata/` – information related to genome accessions and input datasets

## Data availability

Genome assemblies analyzed in this study were obtained from publicly available genomic databases. Accession information is provided in the manuscript and supplementary material.

## Reproducibility

The scripts included in this repository document the main computational steps used in the study. Large genome assembly files and HPC intermediate files are not included.
